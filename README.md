2. Naturaleza del Servicio
Esta aplicación es un servicio estrictamente informativo y de herramientas de cálculo. Los datos sobre cotizaciones de divisas mostrados son recopilados de fuentes y APIs públicas de libre acceso.

No es un servicio financiero: no realiza transacciones, no custodia fondos y no opera con criptomonedas; «USD según BCV» y «USDT» son únicamente referencias de precio. # Política de Privacidad
Última actualización: 29 de octubre de 2026.

1. Responsable
La aplicación «Calculadora de Precios Venezuela» es desarrollada y administrada por Alexander Galindez, desarrollador independiente. Contacto: galindez858@gmail.com.

2. Datos que recopila la aplicación
Ninguno. La aplicación no requiere cuenta, no solicita permisos sensibles (ubicación, contactos, cámara, micrófono o archivos), no incluye publicidad y no usa herramientas de análisis ni de seguimiento. Solo utiliza el acceso a internet.

3. Datos que se guardan en tu dispositivo
El historial de cálculos que guardas (montos, tasas utilizadas y el nombre opcional del producto o servicio), las últimas tasas descargadas y algunas preferencias de uso (como el tema o el color). Se guardan únicamente en el almacenamiento de la aplicación en tu dispositivo, no se envían al desarrollador ni a terceros, y puedes borrarlos con el botón de borrar el historial, desinstalando la aplicación o borrando sus datos desde los ajustes de Android.

4. Conexiones a internet
Para mostrar las tasas de cambio, la aplicación consulta servicios públicos de terceros (Yadio, DolarApi y chitty-bcv-api, indicados en la ventana «Acerca de»). Como ocurre con cualquier conexión a internet, esos servicios pueden recibir datos técnicos como la dirección IP, y se rigen por sus propias condiciones y políticas. La aplicación no les envía tu historial ni tus cálculos.

Búsqueda de actualizaciones (versión de distribución directa, fuera de Google Play): al pulsar «Buscar actualizaciones», la aplicación consulta el servicio público de GitHub para saber si existe una versión nueva. Esa consulta no incluye tu historial ni tus cálculos, y GitHub puede recibir datos técnicos como la dirección IP.

5. Compartir y enlaces externos
Si usas «Copiar resultados» o «Compartir», la información sale solo hacia la aplicación que tú elijas. Los enlaces a sitios externos se abren en tu navegador, que se rige por sus propias políticas.

6. Google Play
Si descargas la aplicación desde Google Play, Google puede tratar datos según sus propias políticas (por ejemplo, instalaciones o errores). El desarrollador puede ver estadísticas generales que ofrece Google Play, sin información que te identifique.

7. Menores
La aplicación no está dirigida a niños y no recopila datos personales de nadie.

8. Cambios
Si esta política cambia, se publicará la versión actualizada en esta página y en la ventana «Acerca de» de la aplicación.
